# The Last Broadcast

*Halloway Falls, Ohio — Tuesday, October 23, 1962.*

Viewers of WKVR-TV Channel 7 keep reporting a second, faint picture on their sets: programmes
the station says it never aired. You are the Federal Communications Commission field engineer
sent to find out where it comes from.

A story-driven investigation mod for **Minecraft Java 1.21.1 / Forge 52.1.x / Java 21**.

## Install

1. Install Minecraft Forge for 1.21.1 (52.1.0 or newer).
2. Put `TheLastBroadcast-1.0.0-forge-1.21.1.jar` in your `mods` folder.
3. Create a **new** world. On first join the WKVR station is built in front of the spawn point
   and you are placed at its entrance with your field kit.

Works in singleplayer and on dedicated servers (all players share one case file).

## Playing

- **Use** people to talk, machines to operate them, cabinets to take documents.
- **Sneak-use** a television to switch it on/off; **sneak-use** the tape deck to eject a reel.
- Your **case file** (item, or the evidence board in Master Control) lists every piece of
  evidence. Tick two items and press **Compare** to look for a contradiction.
- The **field-strength meter** shows a live reading while held; use it to log a bearing.
- Subtitles are always on for broadcasts, telephone audio and conversations.

Tips without spoilers: talk to the night operator first, read everything, record anything
strange, and remember that a tape deck can do more than play forwards.

## Building

```
./gradlew build          # jar in build/libs/
./gradlew runClient      # dev client
./gradlew runServer      # dev server
```

Assets are generated by the scripts in `tools/` (Python 3 with Pillow, numpy, scipy; ffmpeg):

```
python3 tools/gen_content.py        # story content JSON
python3 tools/gen_broadcast_art.py  # broadcast atlas
python3 tools/gen_block_assets.py   # textures, models, blockstates, skins, lang, loot
python3 tools/gen_sounds.py         # all audio + sounds.json (run after gen_block_assets)
```

See `docs/DEVELOPER.md` for adding broadcasts, clues, characters and locations.
